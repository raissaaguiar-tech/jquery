Passo a passo

O código jQuery por trás de cada demonstração: entenda o que cada bloco faz antes de descomentá-lo no script.js.

⚙️ Antes de começar

⚡

O ponto de partida

Todo o código fica dentro do $(document).ready().

Esse método espera o HTML carregar por completo antes de executar o JavaScript. Sem ele, o código poderia rodar antes dos botões existirem na página — e nada funcionaria.

script.js — base 
// Espera o HTML carregar antes de executar o código
$(document).ready(function () {

  // todo o código jQuery fica aqui dentro

});

📋 Os 5 tópicos

1

Manipular conteúdo

Métodos usados: .click() e .text()

O padrão do jQuery é sempre o mesmo: selecione e aja. Aqui, $("#frase") encontra o parágrafo pelo id e .text() troca o conteúdo quando o botão é clicado. Para mudar estilos, o caminho é parecido: $("#frase").css("color", "blue").

script.js — bloco 1 
$("#btn-texto").click(function () {
  $("#frase").text("Texto alterado com jQuery! 🎉 O método .text() fez isso em uma linha.");
});
2

Efeitos e animações

Método usado: .slideToggle()

O .slideToggle(400) alterna entre mostrar e esconder o painel com uma animação de 400 milissegundos. É a família de efeitos mais famosa do jQuery: também existem .fadeIn(), .fadeOut(), .slideUp(), .slideDown() e .animate().

script.js — bloco 2 
$("#btn-slide").click(function () {
  $("#painel").slideToggle(400);
});
3

Lista dinâmica

Métodos usados: .val(), .append(), .on() e .fadeOut()

O .val() lê o que foi digitado no campo, e o .append() insere o novo item <li> na lista. O .on("click", "li", ...) usa delegação de eventos: funciona até nos itens criados depois. E o .keydown() faz a tecla Enter também adicionar.

script.js — bloco 3 
$("#btn-add").click(adicionar);
$("#item").keydown(function (e) {
  if (e.key === "Enter") adicionar();
});

function adicionar() {
  const texto = $("#item").val().trim();
  if (texto !== "") {
    $("#lista").append($("<li>").text(texto));
    $("#item").val("").focus();
  }
}

// remove o item ao clicar nele
$("#lista").on("click", "li", function () {
  $(this).fadeOut(300, function () {
    $(this).remove();
  });
});
4

Formulário

Métodos usados: .val(), .addClass() e .removeClass()

O .val() lê o nome digitado. Se o campo estiver vazio, trocamos as classes do feedback — o CSS pinta de vermelho; se tiver nome, pintamos de verde. Repare no encadeamento: como todo método jQuery retorna o próprio objeto, dá para chamar vários em sequência.

script.js — bloco 4 
$("#btn-ola").click(function () {
  const nome = $("#nome").val().trim();
  if (nome === "") {
    $("#saudacao").removeClass("ok").addClass("erro").text("⚠️ Digite seu nome!");
  } else {
    $("#saudacao").removeClass("erro").addClass("ok").text("Olá, " + nome + "! 😄");
  }
});
5

Modo escuro

Métodos usados: .toggleClass() e .hasClass()

O .toggleClass("escuro") liga ou desliga a classe no <body>. Como todas as cores do site são variáveis CSS, o tema inteiro muda de uma vez — o JavaScript só alterna a classe, quem pinta é o CSS. O .hasClass() apenas verifica se a classe está aplicada.

script.js — bloco 5 
$("#tema").click(function () {
  $("body").toggleClass("escuro");
  const escuro = $("body").hasClass("escuro");
  $(this).text(escuro ? "☀️ Modo claro" : "🌙 Modo escuro");
});
